Sql day_5:
------------

Constraints are rules applied to a table columns in MySQL to ensure that only valid and accurate data is stored in the database..


in simple words:
----------------

constraints = rules that control the data entered into a table.

why do we use constraints?
----------------------------

constraints are used to 

1. Maintain data integrity 
2. prevent invalid data entry.
3. Avoid duplicate records.
4. Ensures relationships b/w tables, make the database reliable and consistent.



integrity constraints
-----------------------

1. not null 
-----------
The not null constraints ensures that a column cannot contain NUll(empty) values. Every row must have a values for that column.
not null: doesn't allow null values. 
------------
2. unique:
-----------------
The unique key constraints ensures that all values in a column are different, duplicate values are not allowed. 
-------------------------
3. primary key:
------------------
combination of unique+not null
--------------------------
4. composite key:
--------------------
If we applied more than one column as primary keys then we should go for composite key constaints this contain is applicable only for table level not at column-level. 
------------------------------
5. foreign key
------------------------
A foreign key creates a relationship b/w two tables. It ensures that value in the child table must already exsists in the parent table...
------------------------
6. default
------------
The default constaint automatically assigns a predefined value if no value is provided during insertion.
------------------
7. check
------------
The check constaint ensures that values satisfy a specified condition before insertion or update.
-----------

Referential Actions.
---------------------

Referential actions define what happens to child table data when parent data is updated or deleted.

on delete cascade, on Update cascade

on delete set null on update set null,


EG:
