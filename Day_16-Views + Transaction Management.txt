Views
------
a view is a virtual table created from the result of select query.

it doesn't normally stores the actual data separately instead it stores the SQL query and whenever you accesses the view, MySQL retrieves the data from the underlying tables.

why do we need views
--------------------
1. simplify complex queries.
2. reuse query logic.
3. data security.
4. simplified reporting.










diff btw table view
-------------------
-->table physically stores the data.
-->view is virtual table based on query.


-->can stores records directly.
-->usually doesn't store separate data.


-->create using create table.
-->create using create view.


-->it contains all table data.
-->can show selected rows/columns.


-->used for permanent data storage.
-->mainly used for abstract, security, and reusable queries.


create view syntax
-------------------
-->
create view view_name as
select column from table
where conditions.


altering view
-------------
alter view_name as
select new_columns from new_tables
where new_conditions;



drop view
---------

drop view_name;
