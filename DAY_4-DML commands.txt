----------

* REMOVES THE TABLE OR OBJECT
* TABLE STRUCTURE+DATA
* TABLE STRUCTURE REMOVED
* PERFORMACE IS SLOW(DUE TO FULL REMOVAL)
 
DELETE:
-------

* REMOVES SPECIFIC ROWS FROM THE TABLE
* SPECIFIC ROWS(BASED ON CONDITIONS)
* TABLE STRUCTURE INTACT
* PERFORMACE IS SLOWER(ROW -BY-ROW)

TRUNCATE:
--------

* REMOVES ALL ROWS, KEEPS STRUCTURE
* ALL ROWS
* TABLE STRUCTURE IS INTACT
* PERFORMANCE IS FAST(BULK DELETION)
