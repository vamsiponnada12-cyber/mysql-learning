Set operators:
--------------
UNION
---------
combine results  from two queries and removes duplicate rows. columns must have the same number and type

UNION ALL
---------
combines results from two queries and include all rows. including duplicates. column must have the same number and type

INTERSECT
----------
returns rows that are common to both queries. columns must have the same number and type.

note: MySQL does-not support intersect directly

MINUS/EXCEPT
-------------
returns rows from the first query that are not present in the second query. columns must have the same number and type

JOINS:
------
a join in MySQL is used to combine rows from two or more tables based on related columns


example
--------
employees table --> employee details
department table --> department details

if you want to se which employee belongings to which department. you need to join these two tables.

why do we need joins
---------------------
to fetch data from multiple tables in a single query.
to reduce data duplications(instead of keeping everything in one table).
to implement relationships like(one-to-one, one-to-many, many-to-one, many-to-many).
4. to generate reports and analytics combining diff datasets.


types of joins:
----------------
inner join
---------------
return only the rows that have matching values in both tables.

syntax
--------
select columns from table1 inner join table2 on table1.common_column=table2.common_column;

2. right join
-------------
returns all rows from the right table and the matched rows from the left table. if no match null appear for the left table column .

syntax
-------
select columns from table1 right join table2 on table1.common_column=table2.common_column;

3. left join
-------------
return all rows from the left table and the matched rows from the right table if no match null values appear for the right table columns.

syntax
------
select columns from table1 left join table2 on table1.common_column=table2.common_column;

4. full join
-------------
to simulate the use the UNION of the left join and right join.

syntax
---------
select columns from table1 left join table2 on table1.common_column=table2.common_column;
Union
select columns from table1 right join table2 on table1.common_column=table2.common_column;

5. cross join
-------------
returns cartesian product--> every row from the first table with every row from the second table.

syntax
-------
select columns
from table1
cross join table2;
 
6. self join
--------------
a table joined with itself.

syntax
------
select a.columns,b.columns
from table1 a 
self join table1 b
on a.column_column=b.common_column;
